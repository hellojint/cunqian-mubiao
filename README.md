# 存钱计算器

一个基于 Python tkinter 的智能储蓄计算小助手，根据月工资收入给出存钱建议，并支持设定目标金额计算达成时间。

## 环境要求

- Python 3.6+
- tkinter（Python 自带，无需额外安装）

## 快速开始

```bash
python savings_calculator.py
```

## 使用说明

### 1. 计算建议存钱金额

启动程序后，在底部输入框输入你的**月工资收入**（元），按回车或点击「发送」。

程序会根据工资档位自动计算建议存钱金额：

| 月工资 | 存钱策略 |
|--------|----------|
| ≤ 3000 元 | 建议先保证基本生活开销 |
| 3000 ~ 6000 元 | 最低存 1000 元，最高不超过 35% |
| 6000 ~ 10000 元 | 保留 2750 元，剩余存起（上限 50%） |
| > 10000 元 | 保留 5000 元，剩余存起（上限 50%） |

### 2. 目标差距计算

计算完成后，点击右下角「目标差距」按钮，弹出子窗口支持两种模式：

- **输入目标金额 + 期望月数** → 反推每月需存多少，判断是否可行
- **仅输入目标金额** → 用当前每月存款正推需要多久达成

### 3. 重新计算

点击「重新计算」按钮可清空对话，重新输入新的工资金额。
